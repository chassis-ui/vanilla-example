Vanilla HTML and Chassis CSS

One HTML file, a few stylesheets and no framework. Every class on this page comes from Chassis CSS and every icon from Chassis Icons. The colors, the fonts, the corners and the logo are those of the brand the page is built for.

Read the docs View source

Features

Styled by tokens, not by overrides

The same markup takes the look of a brand from its design tokens.

A build per brand

Chassis CSS is compiled with the tokens of one brand. Its fonts, its radii and its shadows reach every component, with no class changed.

Context classes

Add context and a color name to an element, and everything inside it takes that color: text, borders, icons and components.

Light and dark

The page follows the system until the theme menu sets data-cx-theme. Every color has a value for both.

FAQ

How this page works

How does the page get the look of a brand?

The build compiles Chassis CSS with the design tokens of one brand, and copies the fonts and the logo of that brand. The HTML, the script and the stylesheet of the page are the same for every brand.

How does the theme menu work?

It sets data-cx-theme on the html element to light or dark, and removes it for the default, which follows the system. The choice is kept in the browser.

Does the page need JavaScript?

The styles do not. The menus, the dialogs, the combobox and the other interactive components do: the page loads the Chassis JavaScript bundle as a module, and the components start from their data-cx-* attributes.

Does it load anything from another site?

No. The stylesheets, the fonts, the icons and the scripts are files of the site itself, and its Content Security Policy allows nothing else: no inline script and no inline style.

Can I start a project from it?

Yes. The example is under the MIT license, and the repository describes the build and the deployment.
